## Part 1 · Decidir què s'instal·la

Abans de tocar res, planifica. Un tècnic que instal·la sobre la marxa acaba amb un equip ple de coses que ningú sap per què hi són.

Ompli la **taula de decisió** amb el programari que necessita l'empresa per a este curs. Mínim una fila per a cada necessitat:

| Necessitat | Programa triat | Llicència | Per què este i no un altre |
| --- | --- | --- | --- |
| Processar textos | | | |
| Fulls de càlcul | | | |
| Presentacions | | | |
| Base de dades | | | |
| Edició d'imatge | | | |
| Captura de pantalla | | | |
| Compressió de fitxers | | | |
| Lectura de PDF | | | |

La columna de justificació és la important. *"Perquè sí"* o *"perquè ja el coneixia"* no són justificacions: parla de cost, de llicència, de compatibilitat amb el que usen els clients o de requisits de l'equip.

!!! warning "Requisits abans d'instal·lar"
    Comprova que l'equip compleix els requisits mínims de cada programa **abans** de descarregar res. Apunta a l'informe la comparació: requisit demanat contra el que tens realment (RAM, espai lliure, versió del sistema).

## Part 2 · Instal·lar i configurar

Instal·la la suite ofimàtica de l'aula i configura el **compte de Microsoft 365 Online** del centre. Treballaràs amb les dues coses tot el curs, així que les dues han d'estar operatives.

Documenta **cada instal·lació** amb la mateixa fitxa:

- nom i versió exacta del programa,
- origen de la descàrrega (URL completa),
- mètode d'instal·lació (gestor de paquets, instal·lador, portal web),
- durada aproximada,
- incidències, si n'hi ha hagut.

Després, aplica la **configuració de l'empresa**. No és opcional: és el que fa que tots els equips es comporten igual.

| Paràmetre | Valor que ha de quedar |
| --- | --- |
| Idioma de la interfície | Valencià |
| Diccionaris de correcció | Valencià, castellà i anglés |
| Desat automàtic | Cada 5 minuts |
| Carpeta de treball per defecte | La del portafoli |
| Dades d'usuari | Nom real, per a que els comentaris i els canvis s'identifiquen |
| Format de desat per defecte | El que decidiu a [A3](A3_compatibilitat.md) |

## Part 3 · Afegir, llevar i actualitzar

Tres operacions que un tècnic fa constantment i que ací has de demostrar per separat:

1. **Afegir un component**: instal·la almenys **una extensió** útil per a la faena (per exemple, una extensió d'exportació o una plantilla). Explica què aporta.
2. **Llevar un component**: desinstal·la un programa que hages decidit que no cal, o una part d'una instal·lació. Comprova què queda arrere (carpetes de configuració, fitxers orfes) i neteja-ho.
3. **Actualitzar**: deixa tot el programari a l'última versió disponible i documenta com es comprova i com s'aplica una actualització en este sistema.

## Part 4 · L'informe

Redacta l'**Informe d'instal·lació** amb esta estructura:

1. Portada amb identificació de l'equip i de l'autor.
2. Taula de decisió (part 1).
3. Verificació de requisits.
4. Fitxa d'instal·lació de cada programa.
5. Configuració aplicada.
6. Components afegits i eliminats, i actualitzacions.
7. **Registre d'incidències** (format de la [T4](../teoria/4_documentar.md)).
8. Annex: política de formats de l'empresa, resultat d'[A3](A3_compatibilitat.md).

!!! tip "La prova del nou tècnic"
    Abans de lliurar, llig el teu informe imaginant que no saps res del que has fet. Si hi ha un pas que no podries repetir només amb això, falta informació.

## Com s'avalua

Cada criteri es puntua amb un dels quatre nivells de la [rúbrica de l'empresa](../../recursos/avaluacio.md).

**RA1.a · Identificar i establir les fases del procés d'instal·lació — 15 %**

- 🟢 La taula de decisió està completa i cada tria justificada amb criteris professionals. Les fases apareixen ordenades i es distingeix planificació, verificació de requisits, instal·lació i comprovació.
- 🔵 Totes les files completes, però alguna justificació és feble o es dona per suposada alguna fase.
- 🟡 Falten necessitats per cobrir o les justificacions són genèriques (*"és el més conegut"*).
- 🔴 No hi ha planificació: l'informe és una llista del que s'ha anat instal·lant.

**RA1.b · Respectar les especificacions tècniques — 15 %**

- 🟢 Requisits de cada programa comprovats contra el maquinari real, amb xifres, i versions exactes documentades amb l'origen oficial de descàrrega.
- 🔵 Requisits comprovats però sense contrastar amb dades concretes de l'equip, o falta alguna URL d'origen.
- 🟡 Es mencionen els requisits sense comprovar-los, o hi ha descàrregues d'origen no identificat.
- 🔴 No hi ha verificació de requisits, o s'ha descarregat de llocs no oficials.

**RA1.c · Configurar les aplicacions segons els criteris establits — 25 %**

- 🟢 Tots els paràmetres de la taula de configuració aplicats i evidenciats amb captures. Les captures mostren el valor concret, no la finestra genèrica.
- 🔵 Tots aplicats, però alguna evidència és ambigua o falta una captura.
- 🟡 Falten paràmetres per configurar, o les captures no demostren res.
- 🔴 L'equip ha quedat amb la configuració per defecte.

**RA1.d · Documentar les incidències — 15 %**

- 🟢 Registre complet amb símptoma, causa, solució i verificació per a cada incidència. Si no n'hi ha hagut cap, es documenten les comprovacions fetes per a assegurar-se'n.
- 🔵 Incidències registrades però amb algun apartat curt (falta la verificació, o la causa és una suposició).
- 🟡 Les incidències es mencionen de passada, sense mètode.
- 🔴 No hi ha registre, o diu *"cap incidència"* sense cap comprovació.

**RA1.f · Eliminar i/o afegir components — 15 %**

- 🟢 Una extensió instal·lada amb explicació del valor que aporta i un component eliminat amb comprovació de restes i neteja.
- 🔵 Les dues operacions fetes, però sense comprovar què queda després de desinstal·lar.
- 🟡 Només una de les dues operacions.
- 🔴 Cap de les dues, o descrites sense evidència.

**RA1.g · Actualitzar les aplicacions — 15 %**

- 🟢 Tot el programari a l'última versió, amb el procediment de comprovació i aplicació documentat i reproduïble en este sistema.
- 🔵 Actualitzat, però el procediment només s'esmenta.
- 🟡 Actualitzat parcialment o sense documentar com es fa.
- 🔴 Sense actualitzar.

!!! note "Punt de comprensió"
    En revisar el teu informe et faré dues o tres preguntes curtes sobre decisions concretes que hi apareixen. Consulta què significa això a [Com s'avalua](../../recursos/avaluacio.md).
