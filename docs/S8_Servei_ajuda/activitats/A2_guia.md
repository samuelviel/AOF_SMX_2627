**Sessió 10** · lliurament: guia d'una pàgina en PDF
**Avalua:** RA9 <span class="ca">a</span> <span class="ca">c</span>

## El producte

**Una pàgina. Una.** A4, per a imprimir i penjar.

Ha de resoldre les **3-5 tasques més freqüents** de la base de dades de [S7](../../S7_Dades_client/index.md).

!!! warning "Tria per freqüència, no per importància"
    L'error habitual és posar-hi les tasques "importants" (fer una còpia de seguretat, generar l'informe anual). Eixes es fan una vegada al mes i es consulten al manual.

    La guia visual és per al que es fa **cada dia**. Si dubtes, pensa en les preguntes que et farien tres vegades per setmana.

## Requisits

- [ ] **Una sola pàgina A4**, sense excepcions
- [ ] 3-5 tasques, una columna o bloc cadascuna
- [ ] Passos **numerats**
- [ ] Captures **retallades al mínim reconeixible** i anotades
- [ ] **Sense frases senceres:** "Clic a **Clients**", no "A continuació, faràs clic..."
- [ ] Funciona en **blanc i negre** (s'imprimirà així)
- [ ] Identitat corporativa: logotip discret, colors de la marca
- [ ] Un peu amb **on acudir si això no basta**: el manual complet, el vídeo, el telèfon de suport

## Les captures

Reutilitza el criteri de [S5/A2](../../S5_Imatge_empresa/activitats/A2_captures.md): retallades, anotades amb un únic color de ressaltat, sense dades personals.

Ací són més xicotetes que en un manual, així que el retall ha de ser més agressiu: **només l'element del qual parles i el context mínim per a reconéixer-lo**.

## La prova

Imprimeix-la i penja-la a un metre i mig. Mira-la.

| Comprovació | |
| --- | --- |
| Es distingeixen les tasques sense acostar-se? | |
| Es llig el text dels passos a un metre? | |
| Les captures s'entenen en blanc i negre? | |
| Troba algú la tasca que busca en menys de 5 segons? | |

Documenta el resultat i **corregeix el que falle**. Si no tens impressora disponible, fes la prova amb el PDF a pantalla completa i allunyant-te.

## La relació amb el manual

<span class="ca">CA c</span> La guia visual no substitueix el manual: **el complementa**.

Al lliurament, inclou mitja pàgina explicant el **sistema de documentació** que proposeu al client:

| Recurs | Per a què | Quan s'usa |
| --- | --- | --- |
| Guia visual | Les tasques diàries | Penjada a la paret |
| Manual complet | Tot, amb detall | Quan la guia no basta |
| Videotutorial | Aprendre una tasca de zero | Formació inicial |
| Suport telefònic | Quan res de l'anterior funciona | Últim recurs |

I una frase per a cada recurs sobre **qui el manté i cada quant es revisa**. Documentació sense manteniment caduca i acaba enganyant.

## Com s'avalua

### RA9.a) Guies visuals elaborades — 65 %

- 🟢 Una pàgina, 3-5 tasques triades **per freqüència real** i justificades, passos numerats sense frases senceres, captures retallades i anotades, llegible en blanc i negre i a distància. La prova s'ha fet, s'ha documentat i s'ha corregit el que fallava. Identitat corporativa aplicada.
- 🔵 Guia d'una pàgina ben construïda, però amb algun bloc massa dens o la prova feta sense correccions posteriors.
- 🟡 Més d'una pàgina, o escrita en prosa amb frases senceres, o amb captures massa grans o sense retallar.
- 🔴 És un manual reduït, no una guia visual: text corregut, sense estructura de tasques.

### RA9.c) Manuals d'usuari per a instruir — 35 %

- 🟢 El sistema de documentació està plantejat amb els quatre recursos, cadascun amb el seu ús, qui el manté i cada quant es revisa. La guia i el manual de [S7](../../S7_Dades_client/activitats/A4_entrega.md) són coherents entre si: no es contradiuen ni es dupliquen.
- 🔵 Sistema plantejat i coherent, però sense responsables ni periodicitat de revisió.
- 🟡 Es llisten els recursos sense explicar quan s'usa cadascun.
- 🔴 No hi ha relació entre la guia i la resta de documentació produïda.
